# Dataset Folder Overview

This folder contains source text datasets used by TF-IDF.

## Files and Contents

- `10_short.txt`
  - **Type:** Plain text dataset (short paragraphs)
  - **Content style:** Short/medium paragraphs, readable natural language
  - **Entries:** 10 text rows (one paragraph per line)
  - **File length:** 11 lines (last line is trailing newline)

- `1000_long.txt`
  - **Type:** Plain text dataset (long texts)
  - **Content style:** Long lines (each line is a long text, typically around 1000+ words)
  - **Entries:** 1000 text rows (one long text per line)
  - **File length:** 1001 lines (last line is trailing newline)

## Notes

- For `.txt` datasets in this folder, **one line = one text row**.
- Line counts can be one more than row counts because of a trailing newline at the end of file.
